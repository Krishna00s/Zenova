\# Visual Rebranding



Zenova is entering a new visual direction.



The previous dark, black-and-gold identity served as an exploration phase.



After reviewing the overall experience, the project is now moving toward a calmer, more timeless visual language.



This is not a temporary theme change.



This becomes the primary design language of Zenova Version One.



Every existing section should gradually be updated to match this direction.



Do not mix the old and new styles.



The entire homepage should feel like it was designed at the same time by the same team.



\---



\# New Visual Identity



Primary Background



Soft White



Secondary Background



Warm Lavender



Accent



Deep Violet



Supporting Accent



Muted Lavender



Text



Near Black



The website should feel bright, breathable and welcoming.



Contrast should come from typography rather than dark backgrounds.



The overall atmosphere should communicate calm confidence.



\---



\# Design References



The images inside the `design/` folder now become the primary visual references for Zenova.



These references define



\- typography

\- spacing

\- composition

\- card styling

\- photography

\- color balance

\- visual rhythm

\- atmosphere



They should inspire every section of the homepage.



Do not recreate them exactly.



Instead understand why they work.



\---



\# Refactoring Existing Sections



The Hero section should be redesigned to match the new visual language while preserving its structure and messaging.



The navigation should adopt the new palette.



Cards should inherit the new materials and gradients.



Buttons should follow the updated design system.



Typography should become more editorial and elegant.



Backgrounds should transition to the new soft white and lavender palette.



Icons should become lighter and more refined.



Every section should feel like part of one complete experience.



Avoid leaving remnants of the previous dark theme.



The transition should feel complete and intentional.



\---



\# Color Philosophy



The new palette should not feel feminine or decorative.



It should feel calm.



Premium.



Architectural.



Minimal.



Editorial.



The colors exist to create atmosphere rather than attract attention.



Use deep violet only as an accent.



Whitespace should become one of the strongest visual elements of the website.



Lavender should support the experience, not dominate it.



\---



\# Typography Philosophy



Typography now becomes one of Zenova's strongest brand assets.



Headings should feel editorial.



Body text should remain highly readable.



Avoid oversized paragraphs.



Use line breaks intentionally.



Allow typography to create rhythm throughout the page.



Visitors should be able to understand the structure of the page simply by scrolling.



Typography should feel confident without being loud.



\---



\# Final Objective



When every section has been updated,



the homepage should no longer feel like multiple design iterations combined.



It should feel like one carefully crafted product experience.



Every section should belong to the same visual family.



Every interaction should reinforce the new identity.



This visual language now becomes the standard for all future pages of Zenova.
